# 哼唱转乐器轨（暂名 HumToTrack）产品需求

## 1. 背景

脑子里有旋律时，最顺手的表达方式是直接哼。但"哼出来"到"电脑里一条能用的乐器轨"之间隔着：找音源、对节奏、拖音符、调音准。这一步太麻烦，灵感就凉了。

需求一句话：**哼一段，直接得到一条能拖进库乐队用的 MIDI 轨。**

## 2. 目标用户与场景

- 用户：只有我自己（单人自用，不是产品，不做分发）。
- 环境：Mac + 库乐队（GarageBand）作为音源和最终混音场所。
- 水平：非专业制作人，会用一点库乐队。

场景 A（旋律）：
灵感来了 → 打开工具按一下录音 → 哼 8~16 小节 → 点停止 → 选钢琴/吉他 → 几秒后拿到 `.mid` → 拖进库乐队 → 换成想要的音色 → 继续叠别的。

场景 B（鼓）：
嘴里"哒哒 哒 哒哒哒"打一段节奏 → 选鼓 → 拿到鼓 MIDI（底鼓/军鼓/踩镲）→ 拖进库乐队。

## 3. 核心价值

把"哼"到"可用轨道"之间的操作压缩成：**按一下录、按一下停、选乐器、拿文件。**

不追求专业精度，追求"马上能听见、能拖走"。宁可少一个功能，不多一步操作。

## 4. 功能清单

### 必须有（V1）

| 编号 | 功能 | 说明 |
|---|---|---|
| F1 | 一键录音 | 点一下开始，再点一下结束；显示录音时长和电平 |
| F2 | 选择乐器 | 钢琴 / 吉他 / 鼓 三选一。吉他：单音，简单版 |
| F3 | 音高转 MIDI | 单声部哼唱 → 音符序列（音高 + 起止 + 力度） |
| F4 | 节奏量化 | 自动估速，对齐到 1/16 网格；允许手动改 BPM |
| F5 | 导出 .mid | 标准 MIDI 文件，固定目录 `~/Music/HumToTrack/`（MVP 阶段先落 `mvp/out/`），文件名带时间戳和乐器 |
| F6 | 一键定位文件 | 处理完直接给出文件，能一键在 Finder 中显示 |
| F7 | 鼓模式分件 | "哒哒"节奏 → 底鼓/军鼓/踩镲，映射到 GM 鼓位 36/38/42 |
| F8 | 重录替换 | 不满意整条重录覆盖（不做局部修补） |

### 应该有（V1.1）

- F9 量化力度可调（1/8 网格 / 不量化）
- F10 内置试听：处理完在工具里直接播一遍
- F11 自动去静音头尾、轻度降噪
- F12 保留原始干声 wav，便于回溯

### 可以有（V2+）

- 和弦化吉他（分解和弦 / 扫弦）
- 哼唱自动配鼓（现在不做，见"不做"）
- 一次出多轨
- 自动写入库乐队工程

## 5. 不做（范围边界）

- 不做钢琴卷帘 / 音高修正界面 —— 改错靠重哼
- 不内置专业音源，不做混音、母带 —— 音色和后期全交给库乐队
- 不做多轨对齐、不做自动编曲、不做和弦识别
- 不做账号、云端、分享、协作
- 只支持 macOS + 库乐队，不做 Windows / Linux / 移动端
- 不上架、不做安装包分发，只自己用

## 6. 验收标准

1. 输入一段 8 小节人声哼唱（允许轻微跑调），处理时间 < 15 秒。
2. 输出 `.mid` 拖进库乐队、选任意音源能正确出声，音高走向与原哼唱一致（主旋律音高正确率 ≥ 90%）。
3. 节奏：在给定 BPM 下，音符起音与哼唱实际起音的误差 < 1/16 音符。
4. 鼓模式：一段 4/4 的"哒哒"节奏，能正确分出 kick / snare / hihat 三类事件，数量误差 ≤ 10%。
5. 全流程（点录音 → 拿到 .mid）≤ 3 步，全程不碰命令行。

## 7. 待拍板

- **是否要"自动送进库乐队"**：库乐队没有开放接口，自动导入只能靠模拟菜单点击，脆弱易坏。建议 V1 只出文件 + 一键定位，手动拖入。
- **吉他单音是否可接受**：V1 只出单音线条，听起来像"吉他音色的单音"，不是扫弦。
- **BPM 来源**：自动估速对无伴奏哼唱不稳，V1 建议以"手动给 BPM"为准，自动值只做默认。
